# TypeRush — AZERTY typing tutor

TypeRush is a browser-based typing tutor built with plain HTML, CSS and JavaScript modules.

## Start locally
1. Unzip the project.
2. Open the `typerush` folder in VS Code.
3. Start `index.html` with the Live Server extension, or run `python -m http.server 8000` from the `typerush` folder and open `http://localhost:8000`.

## Features
- Guided AZERTY lessons from hand placement through letters, words, capitals, punctuation and sentences.
- Lessons explain finger placement and give a short tip before each exercise.
- Three practice prompts per lesson; incorrect attempts are highlighted and the prompt must be typed correctly to advance.
- Completed lessons are saved in localStorage.
- Separate Rush mode for timed typing tests, plus progress, theme toggle and multilingual prompts.

## Notes
Progress is stored in the browser on this device. The virtual keyboard highlights relevant keys as a visual aid; finger guidance is currently provided as lesson text rather than a hand animation.
